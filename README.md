# FIRP - Fortran Interpreter
(noun) : not ferp

A modern interpreter for Fortran, built in Rust.

## Quick Start

### Build
```bash
cargo build
```

### Run
```bash
cargo run
```

### Test
```bash
cargo test
```

## Examples

See `examples/` for sample Fortran programs:
- `hello.f90` - Simple hello world
- `arithmetic.f90` - Basic arithmetic
- `factorial.f90` - Recursive functions
